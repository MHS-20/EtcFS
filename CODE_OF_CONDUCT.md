# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct.

## The short version

Be respectful. Assume good faith. Critique code and designs, not people.
Harassment, personal attacks, and demeaning or discriminatory language are not
welcome in issues, pull requests, commit messages, or any other project space.

## Scope

This applies in all project spaces — the issue tracker, pull requests, code
review, and commit history — and whenever someone is representing the project
in public.

## Reporting

Report unacceptable behaviour privately to the maintainers at
<muhamad.salman2001@gmail.com>. Reports are handled confidentially, and the reporter's
identity is not shared with the person reported.

Maintainers who do not follow or enforce this code in good faith are subject to
it themselves.

The full text, including the enforcement guidelines the maintainers follow, is
at the link above.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
